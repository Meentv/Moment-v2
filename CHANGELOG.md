# Changelog

## 2.0.0 — React-only blueprint implementation

- Applied the MOMENT V2 blueprint with an explicit React-only scope decision.
- Added the warm rose/coral design system, responsive workspace shell and public pages.
- Implemented real task, project and note workflows with validation, confirmation and undo.
- Added day/week/month planning and a timestamp-based focus timer with history.
- Added global search, keyboard shortcuts, accessible dialogs/menus and theme preferences.
- Added browser persistence, corruption recovery, JSON backup/import and explicit data deletion.
- Added service/storage/timer tests, React acceptance tests and a Playwright/axe browser check script.
- Kept Supabase/SQL deferred; no credentials, fake accounts, fake metrics or Vanilla implementation.
